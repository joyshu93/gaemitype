# 결과 장면 원고 적용 및 검증

후속 상태: 아래는 로컬 구현 라운드의 기록이다. 이후 사용자가 별도로 운영 반영을 승인했고, `22341be`의 [운영 배포·실제 사이트 검증](2026-10-20-result-scenes-production-verification.md)을 완료했다. 아래 당시 미배포 기록은 이력을 위해 보존한다.

확인일: 2026-10-20 KST. 사용자가 **‘이 원고대로 결과 장면에 적용하고 검증까지 해줘’**라고 승인했다. 승인한 장면 원고를 최신 작업트리에 적용하고 자동 검사와 로컬 빌드 화면 검증을 마쳤다. 운영 배포와 AdSense 재제출은 수행하지 않았다.

## 적용 범위

- 기준: `.worktrees/approved-experience`, HEAD `572c8e6e661ba5ecf60535dbcb67e30d490a7a70` 위 미커밋 변경.
- 승인 문서: [결과 장면 비교와 교체 원고](2026-10-20-result-scenes-copy-proposal.md).
- 제품 변경 파일: [type-profiles.ts](../../src/data/type-profiles.ts).
- `SCENES` 상수 8개를 선언하고 16타입의 `scenes` 두 항목에 매핑했다. 원고를 공통으로 관리하는 방식은 기존 `REFLECTIONS` 구조와 맞췄다.
- 타입명·headline·description·reflections·shareText는 변경 전과 동일하다. 질문·채점·결과 모드·컴포넌트·공유·광고·의존성도 변경하지 않았다.
- 이전 루트와 작업트리의 문서 변경을 보존했다. 루트 main 동기화, 커밋·푸시·배포는 하지 않았다.

| 변경 범위 | 장면 외 프로필 필드가 변경 전과 동일. 제품 `src` diff는 `type-profiles.ts` 한 파일 |
| 기존 테스트 | `npm.cmd test`: 19개 통과, 실패 0. 집계·결과 모드·공유·가이드·광고 검사 포함 |

| 모바일 | 360×800 브라우저 viewport에서 ALRD 세 모드와 PLRC 확인. 문서 너비 345px. PLRC 장면 두 항목의 가로 넘침·높이 잘림 없음 |
| 모바일 시각 확인 | ALRD 장면 섹션 캡처에서 공통 고지와 두 장면의 줄바꿈 확인 |
| 데스크톱 | 1440×1000 viewport에서 ALRC 확인. 문서 너비 1425px. 캡처에서 축·장면·돌아볼 질문의 배치와 문장 표시 확인 |
| 가이드 이동 | PLRC 결과의 ‘내 결과를 더 잘 읽는 방법’을 클릭해 `/guides/reading-results`와 해당 제목 도착 확인 |
| 브라우저 오류 | 검증 탭에서 error 로그 0개 |

viewport 검증은 실제 휴대폰에서의 조작 검증과 다르다. 입력한 answers는 메인이 만든 테스트 입력이며 사용자 조사 자료가 아니다. 공유 링크 복사 버튼의 클립보드 동작과 20문항 전체 완주를 이번에 다시 실행했다고 주장하지 않는다.

빌드에는 `caniuse-lite` 데이터가 7개월 오래됐다는 Browserslist 안내가 있었다. 빌드는 성공했고 이번 원고 변경 범위에서 의존성을 갱신하지 않았다.

검사 도구를 두 곳 보정했다. 최초 HTTP 검사기는 속성 없는 `<li>`를 세지 못해 실패했으므로 실제 HTML을 확인해 태그 패턴을 수정했고 16개 경로 검사를 다시 통과했다. 가이드 도착 확인에서는 브라우저 도구가 지원하지 않는 heading의 `level` 필터 대신 실제 제목을 정확히 지정해 확인했다. 두 건 모두 검사 코드·호출 보정이며 제품 소스 수정 사유가 아니었다.

역할 간 충돌은 없었다. 메인은 승인 범위와 원고 일치를 확인하고, 역할 검토가 대신하지 않은 실제 빌드·화면 검증을 수행했다. 이번 결론은 **승인 원고의 로컬 적용과 검증 완료**이며 운영 반영 또는 AdSense 심사 충족 판정이 아니다.

## QA: 오해 가능성

구체적인 장면을 개인 행동의 관찰 기록이나 예측으로 읽을 수 있다. 모든 모드에 기존 ‘타입 공통 예시이며 실제 선택 기록 아님’ 고지를 유지했고 개인 모드의 실제 선택 사례와 분리되는지 확인했다. 코드 전용·잘못된 답변에 개인 횟수나 사례가 생기지 않았다.

## QA: 금지 표현

추가 원고에서 투자 추천, 수익·위험 회피 보장, 능력 우열, 검증된 진단 표현을 발견하지 못했다. 이 변경이 AdSense 승인을 보장하거나 실제 사용자 효용을 입증한다는 표현도 사용하지 않는다.

## QA: 수동 검증과 남는 한계
