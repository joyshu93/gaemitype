로컬 확인은 worktree에서 `npm run start -- --hostname 127.0.0.1 --port 3017`로 실행한 빌드를 사용했다. 결과 미리보기는 [검증용 ALRD 응답](http://127.0.0.1:3017/result?code=ALRD&answers=01010010100101001010&source=answers)에서 볼 수 있다. 이 로컬 주소는 서버가 실행 중일 때만 열리며 운영 서비스 주소가 아니다.
