## 3. 실제 20문항과 두 선택지

- 계산 중간 페이지의 별도 화면 체험. 마지막 문항에서 결과로 도달한 동작은 확인했지만 중간 계산 화면을 독립적으로 평가하지 않았다.
- `처음부터` 버튼의 초기화 동작, 새로고침/브라우저 종료 후 미완료 응답 복원. 새 테스트 CTA로 첫 문항 진입은 확인했다.

- 완전히 다른 브라우저/기기의 저장 데이터 없는 수신 환경. 새 탭과 코드 전용 URL에서는 응답 모드와 구분됨을 확인했다.
