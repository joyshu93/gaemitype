## 로그인 없는 공개 HTTP 확인

PowerShell의 공개 GET 요청으로 상태·최종 URL·본문/Content-Type을 확인했다. 인증 쿠키나 Vercel 보호 우회 값을 사용하지 않았다. 처음 샌드박스의 TLS 인증 오류가 발생해 허용된 네트워크 실행으로 재확인했다.

- `/`, `/about`, `/privacy`, `/guides`, 가이드 3개 모두 HTTP 200, 최종 호스트 `gaemitype.vercel.app`, 실제 서비스 HTML과 해당 제목을 반환했다. 홈 소유권 확인 메타태그도 유지됐다.
- ALRD·PTIC 코드 전용 결과는 HTTP 200 및 현재 타입 제목을 반환했다. canonical·OG 이미지가 각각 운영 도메인의 코드 결과·PNG를 가리켰다. 홈·소개·개인정보 페이지에는 이번 응답에서 canonical/OG 이미지가 없었으며 새로 추가하지 않았다.
- `/results/ALRD.png`: HTTP 200, `image/png`, 2,050,101바이트. `/results/PTIC.png`: HTTP 200, `image/png`, 2,786,586바이트. 양쪽 PNG 시그니처 `89-50-4E-47-0D-0A-1A-0A` 확인.
- `/robots.txt`: HTTP 200, `text/plain`, 운영 Host·Sitemap 및 `/calculating` Disallow 확인.
- `/sitemap.xml`: HTTP 200, `application/xml`, 16타입·가이드 등 모든 loc이 운영 도메인이고 개인 answers 없음.
- `/ads.txt`와 `/google024ec439f41db987.html`: HTTP 200, 기존 선언/소유권 확인 본문 유지. 광고 활성화나 심사 상태 확인을 의미하지 않는다.

실제 메신저가 가져간 화면·캐시·썸네일 배치까지 검증한 결과는 아니다.

## QA 분류와 남은 확인

**오해 가능성:** 횟수를 성격 강도·정확도·투자 능력으로 읽는 오해, 공통 장면을 본인 답변으로 읽는 오해, 코드만 있는 링크가 개인 선택까지 포함한다고 읽는 오해를 구분했다. 운영에서 해당 안내와 표시 규칙을 확인했다. 모든 사용자가 오해하지 않는다는 조사 결과는 없다.

**금지 표현:** 투자·종목·포트폴리오 추천, 수익·안전 보장, 매수·매도 신호, 능력 우열이나 기회 포착 능력 단정. 이번 기록도 선택 횟수를 그 근거로 사용하지 않는다. AdSense 반려 원인·승인 가능성에 관한 새로운 가설을 판정하지 않았고 승인을 보장하지 않는다.

**수동 검증 항목:** 실제 휴대폰 Safari/Chrome에서 첫 복사 후 다른 입력란에 붙여넣기, 실제 200% 브라우저 확대, 화면 읽기 도구, 실제 메신저의 운영 URL 미리보기·캐시. 첫 복사가 반복 실패하면 브라우저·첫/재시도·실제 붙여넣기 결과를 기록해 원인을 재현한다. 메신저 전송은 이번 라운드에서 실행하지 않았다.
